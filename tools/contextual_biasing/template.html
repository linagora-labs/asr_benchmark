Contextual Biasing Benchmark

How well speech recognition models write the terms of a list (drug names, rare words, company names) without the list, and when the list is given to the model (prompt, hotwords or boosting). Each run with a list is compared with the run of the same model without it, on the same terms.

Measures

  • F1, P, R: precision, recall and F1 of the list terms (each occurrence of a term of the targets, in the reference and in the transcription).
  • B-WER: word error rate on the words of the list terms of the reference; U-WER: on the other words.
  • FA/h: false alarms per hour, list terms written although not spoken.
  • WER: word error rate of the whole transcription (normalized text).
  • Case of the list terms: a term is correct only if written as in the list given to the model (as in the targets for runs without list); the case of the other words is not checked.
  • Lists: local lists only hold terms of the utterance; the others are global lists (one list for the whole test set). _upper: the same list in capitals, given to check that the model writes the terms as given (to read with "Case of the list terms").
